# 本科生：看懂摘要里的相关性，写好读书报告

[返回场景列表](../README.md) · [完整调用记录](data/03-undergraduate.json)

## 用户问题

我大二，要写读书报告。这是课堂练习用的虚构论文摘要：研究者问卷调查了300名大学生，发现每天运动时间越长，受访者报告的睡眠质量通常越好；控制年龄和性别后，这种关联仍存在。研究没有随机分组，也没有跟踪同一个人的变化。我能不能在报告里写“运动改善睡眠”？帮我讲清这项研究到底发现了什么，再给我一段能放进报告的表述。

<p>可以，但<strong>不能把“运动改善睡眠”当作这项研究证明的结论</strong>。更准确的说法是：这项研究发现了<strong>运动时间与睡眠质量之间的正相关</strong>，而且这种关联在控制年龄和性别后仍然存在；但由于没有随机分组、也没有追踪同一个人的变化，它<strong>不能证明运动导致睡眠改善</strong>。</p>
<p>具体来说，这项研究能支持的是：</p>
<ol>
<li><strong>相关性</strong>：每天运动时间越长的人，通常报告睡眠质量越好。</li>
<li><strong>关联不是由年龄和性别解释的</strong>：控制这两个变量后，关联仍存在。</li>
<li><strong>不能支持因果</strong>：没有随机分配，所以不能排除“睡眠好的人更有精力运动”“其他生活方式因素同时影响运动和睡眠”等反向因果或混杂因素。</li>
<li><strong>不能支持个体内变化</strong>：没有跟踪同一个人，所以不能说明“一个人增加运动后，睡眠会变好”。</li>
</ol>

## 这组有什么变化

原版开头先说“可以，但不能”，中间稿直接回答不能把这项观察研究写成因果结论，并给出可放进报告的段落。回译后的部分句子省去了“受访者报告”这一测量方式，需要对照题目理解；两边关于控制变量已排除影响的说法也偏强。
