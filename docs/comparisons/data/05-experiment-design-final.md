首先，让我们做出判断：这项实验值得进行，但我们需要区分“第二轮提供证据”与“证据本身的实用性”。最小设计是一种2×2对照设计；标记总数和检索次数都是固定的。我们将重点关注最终答案的准确性，以及第一轮的独立答案的多样性，同时考察第二轮是否真的改变了答案，以及所使用证据的比例。

**控制设计**

共有四种条件：相同的问题集、相同的模型，以及相同的随机种子：

1. 无证据：在三个轮次中均不提供任何证据。
2. 仅在第一轮提供证据：在第一轮提供证据，后续轮次保持相同条件。
3. 仅在第二轮提供证据：第一轮给出独立答案，第二轮提供证据。这就是目标条件。
4. 两轮都提供证据：第一轮和第二轮都提供相同的证据集。

关键的比较点是3对1：延迟提供证据是否比完全不提供证据更有意义；3对2：延迟提供是否比从一开始就提供证据更好；4对2和3：反复使用证据是否能带来额外好处。1则作为基准，用于验证证据的整体效果。

**预算分配**

每个问题的总预算是固定的，而非按轮次分配。具体分配方式如下：

- 输入标记总数和输出标记总数的上限是固定的；四种条件均相同。
- 检索次数以及每次检索返回的文档数量，以及截断长度都是固定的。在条件1中，不进行检索，但节省的预算会被转化为等效的讨论轮次或更长的单轮输出，因此“无证据组”的计算资源并不少于其他组。
- 智能体的数量和轮次数量都是固定的；每轮有三个智能体。
- 温度、最大生成长度和摘要提示均相同；只有证据注入的时间不同。
- 每个问题使用多个随机种子（例如3个种子），报告的是平均值，而非个体结果。

如果条件1无法用相同的预算完成，应明确说明“无证据组的预算较低”，结论应限制在“在相同轮次数量下”。

**需测量的指标**

主要指标：使用固定评分标准或人工盲评估来衡量最终总结答案的准确性，评估者不知道具体条件。

次要指标：

- 第一轮中三个智能体答案的一致性率。如果第一轮的表现稳定，那么第二轮的修正空间就会很小。  
- 第二轮答案与第一轮的变化率，以及“从错误变为正确”和“从正确变为错误”的比例。这是评估机制的核心。  
- 证据使用率：在第二轮回答中明确引用证据的比例。  
- 使用证据后的准确性：使用证据后，回答是否仍然正确。  
- 答案的多样性：第一轮中不同答案的数量，以此判断是否真的存在独立的回答。  

**哪些结果表明应停止实验**  
如果出现以下情况，建议停止实验或缩小实验范围：  
- 多个种子实验中，条件3的准确率与条件1相比几乎没有提升，且置信区间为零。  
- 条件3明显低于条件2，说明延迟提供证据导致信息损失，机制存在错误。  
- 第二轮的变化率非常低，且“从正确变为错误”的比例至少与“从错误变为正确”相等，说明证据未被有效利用或存在噪声。  
- 证据使用率极低，表明智能体实际上没有阅读证据，实验所测量的机制并非预期中的机制。  
- 改进仅出现在少数问题上，而这些问题在第一轮中已存在显著分歧；这表明好处来自个别案例，而非稳定的机制。  

如果条件3的准确率相对于条件1有稳定且积极的提升，但在条件2中没有优势，那么结论应为“证据是有用的，但延迟提供它不会带来额外价值”，而非“第二轮提供的证据是有用的”。
