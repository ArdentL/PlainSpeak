## 问题原因

这是 Python 中非常经典的**可变默认参数陷阱**。

在 Python 中，函数的默认参数值**只在函数定义时求值一次**，而不是每次调用时重新创建。所以 `items=[]` 这个空列表在函数定义时就被创建了，之后所有调用都共享**同一个列表对象**。

执行过程：
1. 定义 `add_item` 时，创建了一个空列表 `[]`，绑定到 `items` 的默认值上
2. 第一次调用 `add_item("a")`：往这个列表里 append `"a"` → `["a"]`
3. 第二次调用 `add_item("b")`：**还是同一个列表**，append `"b"` → `["a", "b"]`

所以输出是：
```
['a']
['a', 'b']
```

## 修改后的代码

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item("a"))  # ['a']
print(add_item("b"))  # ['b']
```

## 修改原因

- 用 `None` 作为默认值（`None` 是不可变对象，不存在共享问题）
- 在函数体内部判断：如果调用者没传 `items`，才新建一个空列表
- 这样每次调用都会得到**独立的列表**，不会互相污染

## 补充说明

- 如果确实想利用"共享"特性（比如做缓存/累加器），可以保留原写法，但一定要清楚这是有意为之，并加注释说明
- 同样的坑也适用于 `{}`、`set()` 等可变默认参数
- 判断时用 `is None` 而不是 `== None`，这是 Python 的惯用写法
