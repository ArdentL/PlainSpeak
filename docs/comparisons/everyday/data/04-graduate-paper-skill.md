消融实验就是每次拿掉或替换方法中的一个部件，看性能掉多少，以此判断这个部件贡献了什么。这里完整方法68%，两个对照分别改一个地方。

**两个对照的含义**

- **去掉检索：68%→61%，掉7个百分点。** 说明检索模块在这套设置下对正确率有贡献。但注意，去掉检索同时也改变了输入给Agent的信息，所以它衡量的是“检索+它带来的信息”整体作用，不只是检索算法本身。
- **保留检索、改成单Agent：68%→66%，掉2个百分点。** 说明在两个Agent都拿到检索证据的前提下，双Agent汇总比单Agent多2个百分点。这个对照隔离了“多Agent协作”这一项，检索条件没变。

两个对照合起来看：检索的边际贡献（7点）大于多Agent协作（2点），但这是单次运行的点估计，不能当成稳定差距。

**组会上怎么介绍**

可以按这个顺序说：

1. 先交代设置：测试集200题，完整方法68%，做了两个单变量对照。
2. 报两个数：去检索61%，单Agent66%。
3. 给解读，同时标明局限：检索看起来贡献更大，多Agent约2点；但每个设置只跑了一次、没有置信区间，200题上几个点的差异可能来自题目抽样或运行波动，不能下“显著”的结论。
4. 提下一步：重复运行取均值/方差，或做配对比较（同一批题逐题对比），再判断2点和7点是否稳。

这样介绍既说清了消融在验证什么，也没有把单次点估计说成确定结论。
