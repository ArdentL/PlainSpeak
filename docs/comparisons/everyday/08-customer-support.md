# 客服：回应包裹延误，说明今天会做什么

[返回场景列表](../README.md) · [完整调用记录](data/08-customer-support.json)

## 用户问题

我是网店客服，顾客发来一句：“说好昨天到，今天物流还没动，你们到底管不管？”已知包裹到达中转站后两天没更新，我现在可以联系快递核查，今天下午六点前给顾客一次反馈，但不知道什么时候能送到。帮我拟一条能直接回复顾客的消息。

## 回答对比

左侧是 DeepSeek 提供的原始版本；右侧是另一次对话的回复。在应用该插件的语言规则后，进行了本地中文→英文→中文回译。这两种版本均代表了实际返回的完整文本。

## 这组有什么变化

原文中多次表达了歉意，并提供了额外的说明。右侧内容明确说明会检查送货情况，且下午6点前会给予回复，但送货时间仍未确定。这一版本保留了客户真正关心的行动和截止时间，并未对送货时间作出任何承诺。
