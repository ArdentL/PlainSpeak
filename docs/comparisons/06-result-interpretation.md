# 判断实验中的小幅提升是否支持继续投入

[返回场景列表](README.md) · [调用记录](data/06-result-interpretation.json)

## 用户问题

虚构实验结果：同一组100道任务，方法A在三个随机种子上的成功率是52%、54%、56%，基线是47%、48%、49%；按题目配对 bootstrap，平均差值的95%置信区间是−1到13个百分点。这轮实验花了两天。你觉得现在该继续还是放弃？请解释这些结果支持什么判断，并给下一步最省钱的检查。

<p>先给结论：<strong>这轮结果不足以支持“继续投入”也不足以支持“放弃”，它支持的是“先别下大结论，做一个很便宜的配对显著性/区间检查再决定”。</strong> 如果必须二选一，我倾向于<strong>暂不放弃，但也暂不加码</strong>——因为点估计方向有利，但区间跨 0 且很宽，当前证据等级只够“值得再花小钱确认”，不够“值得投入两天一轮的大实验”。</p>
<p>下面拆开解释。</p>
<h2>这些结果支持什么判断</h2>
<h3>1. 点估计方向一致有利</h3>
<ul>
<li>方法A三个种子：52%、54%、56%，均值约 <strong>54%</strong></li>
<li>基线三个种子：47%、48%、49%，均值约 <strong>48%</strong></li>
<li>平均差约 <strong>+6 个百分点</strong></li>
</ul>
<p>三个种子下方法A都高于基线，方向一致，这是弱正面信号。</p>
<h3>2. 但种子间波动和基线波动都不小</h3>
<ul>
<li>A 的种子间范围 52–56，跨度 4 个百分点</li>
<li>基线 47–49，跨度 2 个百分点</li>
<li>只有 3 个种子，均值差 +6 的估计本身不稳</li>
</ul>
<h3>3. 配对 bootstrap 的 95% CI = −1 到 13 个百分点</h3>
<p>这是关键。它说明：</p>
<ul>
<li><strong>不能排除真实差值为 0 甚至略负</strong></li>
<li>但区间上端到 +13，也不能排除有实际意义的正收益</li>
<li>区间很宽，说明<strong>当前样本量/配对结构下，估计精度不够</strong></li>
<li>“跨 0”不等于“没效果”，只等于“这轮数据不能把效果和噪声分开”</li>
</ul>
<h3>4. 两天成本 vs 当前信息量</h3>
<p>花两天得到的是一个“方向对但不确定”的结果。此时：</p>
<ul>
<li><strong>放弃</strong>：可能丢掉一个 +6 点左右的真实收益，代价可能很大</li>
<li><strong>直接继续大投入</strong>：可能在一个尚未确认的效果上烧更多两天</li>
<li><strong>最合理</strong>：先做低成本确认，再决定是否加码</li>
</ul>
<p>所以这些结果支持的判断是：<strong>效果“可能存在但未确认”，当前应进入“低成本验证”而不是“继续/放弃”的二选一。</strong></p>
<h2>下一步最省钱的检查</h2>
<p>最省钱且信息量最高的检查，不是再跑完整 100 题 × 多种子，而是：</p>
<h3>首选：用已有逐题结果做配对检验 + 看配对差异分布</h3>
<p>如果这轮实验保存了<strong>每题、每个种子、A 和基线的逐题成败</strong>，那么几乎零额外算力成本就能做：</p>
<ol>
<li><strong>按题目配对</strong>，对每个种子算 A−基线 的逐题差值（+1/0/−1）</li>
<li>对 100 题做<strong>配对符号检验或配对置换检验</strong>，看 p 值</li>
<li>看<strong>配对差值均值的标准误</strong>，确认 bootstrap CI 是否因配对方式/重采样单位设置而偏宽</li>
<li>特别检查：<strong>A 赢的题和输的题是否集中在少数题目上</strong>——如果 +6 点主要由少数几道题驱动，泛化性存疑</li>
</ol>
<p>这一步成本几乎为零，因为数据已经有了。</p>
<h3>次选：只加种子，不加题目</h3>
<p>如果逐题数据不完整，最省钱的是<strong>固定这 100 题，只增加随机种子</strong>，比如从 3 个加到 8–10 个。因为：</p>
<ul>
<li>题目配对结构不变，能直接估计种子噪声</li>
<li>不需要扩题、不需要新标注/新任务构造</li>
<li>能显著收窄“平均差值”的区间</li>
</ul>
<h3>不建议现在做的</h3>
<ul>
<li>直接扩到几百题的新任务集：贵，且当前连“这 100 题上是否真有效”都没确认</li>
<li>直接上更大模型/更多训练：在效果未确认前加码，风险高</li>
<li>只看三个种子均值就宣布成功：CI 跨 0，证据不足</li>
</ul>
<h2>一个可执行的决策规则</h2>
<p>可以预先定好：</p>
<ul>
<li>若配对检验 p &lt; 0.05 且差值均值仍 ≥ +4 点 → <strong>继续</strong>，进入下一轮适度加码</li>
<li>若 p 不显著但点估计仍为正、CI 上端仍可观 → <strong>只加种子/加题做确认</strong>，不加方法复杂度</li>
<li>若配对检验显示差值集中在少数题，或加种子后均值差掉到 +2 点以内 → <strong>放弃或转向诊断</strong></li>
</ul>
<p><strong>一句话总结：这轮结果不支持放弃，也不支持直接加码；它支持“用已有逐题数据做零成本配对检验，必要时只加种子”，确认 +6 点不是噪声后再决定。</strong></p>
