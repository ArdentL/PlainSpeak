**先给判断：现在既不该宣布方法A有效，也不该放弃。** 这轮结果只支持“可能有提升，但证据不够”，因为配对 bootstrap 的 95% 区间是 −1 到 13 个百分点，跨过 0，不能排除没有提升。

具体看：

- 三个种子的成功率：A 是 52%、54%、56%，基线是 47%、48%、49%。每个种子下 A 都高 5 到 7 个百分点，方向一致，这是正面信号。
- 但只有 3 个种子、100 道题，种子间波动和题目难度都会影响结果。区间下限 −1 说明“真实平均差为 0 或略负”仍与数据相容。
- 因此当前证据支持的是：**值得做一次更省钱的确认，而不是直接扩大投入，也不是因为区间跨 0 就放弃。**

下一步最省钱的检查，我建议先做**同一批 100 道题上的配对逐题分析**，不再跑新实验：

1. 统计 A 和基线逐题胜负：A 赢多少题、输多少题、平多少题。
2. 重点看 A 赢的题和输的题是否集中在某类任务；如果 A 的净胜题数很少，或赢输都集中在少数题上，提升可能不稳。
3. 用现有逐题结果做配对检验或重采样，确认区间跨 0 是样本量不足，还是存在明显的异质性。

这一步几乎不花额外算力，只重新分析已有记录。若逐题结果显示 A 的净胜题数明显为正、且不是少数题撑起来的，再考虑加种子或加题量；若胜负接近或输赢高度集中，就应优先修实验设计或放弃这条路线。
