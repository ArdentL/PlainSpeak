先给判断：这个实验值得做，但要把“第二轮给证据”和“证据本身有用”分开。最小设计是 2×2 对照，固定总 token 和检索次数，主看最终答案正确率，次看第一轮独立答案的多样性、第二轮是否真的改变了答案，以及证据被引用的比例。

**对照设计**

四个条件，同一批问题、同一模型、同一随机种子集合：

1. 无证据：三轮都不给检索证据。
2. 仅第一轮给证据：第一轮就带证据，后两轮沿用。
3. 仅第二轮给证据：第一轮独立回答，第二轮起给证据。这是你的目标条件。
4. 两轮都给证据：第一轮和第二轮都给同一批证据。

关键比较是 3 对 1，回答“延迟给证据是否比完全不给有用”；3 对 2，回答“延迟是否比一开始就给更好”；4 对 2 和 3，看证据重复出现是否有额外收益。1 是基线，用来确认证据整体有效。

**预算对齐**

总预算按每个问题固定，不按轮次固定。具体做法：

- 固定总输入 token 上限和总输出 token 上限，四个条件相同。
- 固定检索次数和每次返回的文档数、截断长度。条件 1 不检索，但把省下的预算折算成等量的讨论轮次或更长的单轮输出，避免“无证据组只是算力更少”。
- 固定 Agent 数量和轮数，都是三轮三 Agent。
- 温度、最大生成长度、汇总提示词完全一致，只改证据注入时机。
- 每个问题跑多个随机种子（比如 3 个），报告均值而不是单次结果。

如果条件 1 无法用等量预算，就明确报告“无证据组预算更低”，并把结论收窄为“在相同轮数下”。

**看什么结果**

主指标：最终汇总答案的正确率，用固定评分标准或人工盲评，评分者不知道条件。

次指标：

- 第一轮三个 Agent 答案的一致率。如果第一轮高度一致，第二轮给证据的纠错空间就小。
- 第二轮答案相对第一轮的改变率，以及改变中“从错变对”和“从对变错”的比例。这是判断机制的核心。
- 证据引用率：第二轮回答中明确引用检索内容的比例。
- 证据采纳后的正确率：引用了证据的样本里，最终是否正确。
- 答案多样性：第一轮不同答案的数量，用来判断独立回答是否真的独立。

**什么结果建议停止**

出现以下任一情况，建议停止或缩小范围：

- 条件 3 对条件 1 的正确率提升在多个种子下都接近零，且置信区间跨零。
- 条件 3 明显不如条件 2，说明延迟给证据损失了信息，机制方向不对。
- 第二轮改变率很低，且改变中“从对变错”不少于“从错变对”，说明证据没被有效利用或引入噪声。
- 证据引用率很低，说明 Agent 实际上没读证据，实验测的不是你想测的机制。
- 提升只出现在少数问题上，且这些问题第一轮本来就高度分歧，说明收益来自个例而非稳定机制。

如果条件 3 对 1 有稳定正提升，但对 2 没有优势，结论应写成“证据有用，但延迟给没有额外价值”，而不是“第二轮给证据有用”。
