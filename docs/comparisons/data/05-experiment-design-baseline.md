# 小实验设计：第二轮才给检索证据，值不值得？

## 1. 先明确你要验证的假设

你的设计本质上是把"检索证据"从**全程可用**改成**第二轮才注入**。要判断它有没有用，需要拆成两个可证伪的问题：

- **H1（相对无证据）**：第二轮给证据，是否比"全程不给证据"更好？
- **H2（相对全程给证据）**：第二轮给证据，是否不劣于（或优于）"第一轮就给证据"？

只做 H1 容易得出"有用"的结论，但那可能只是"有证据比没证据好"，不能说明"延迟给"这个设计本身有价值。**建议两个对照都做**，否则结论会误导后续决策。

## 2. 对照臂设计（4 个臂，最小充分集）

| 臂 | 第一轮 | 第二轮 | 用途 |
|---|---|---|---|
| A. 无证据 | 无 | 无 | 下界基线 |
| B. 全程证据 | 有 | 有 | 上界基线 / 现行方案 |
| C. 延迟证据（你的想法） | 无 | 有 | 待测 |
| D. 仅第一轮证据 | 有 | 无 | 排除"证据只在第一轮起作用"的混淆 |

D 臂很关键：如果 C ≈ D，说明第二轮的证据根本没被用上，你的"延迟"设计是无效的，只是碰巧第一轮有证据。没有 D，你无法区分"延迟注入有效"和"第一轮注入就够"。

如果预算紧张，最低配是 **A / B / C** 三臂，但要在报告里注明无法排除 D 的混淆。

## 3. 预算对齐（这是最容易做错的地方）

"预算"要分三层对齐，否则比较不公平：

1. **Token 预算**：每个臂的总 token 上限相同（输入+输出）。注意 B 臂第一轮就带证据，输入 token 天然更高——要么给所有臂相同的**总**预算并允许 B 臂第二轮少检索，要么按"每轮预算"对齐并单独报告总消耗。**推荐前者**，因为总成本才是你真正关心的。
2. **检索预算**：C 臂只在第二轮检索一次，B 臂若两轮都检索就是两次。要么让 B 臂也只检索一次（第一轮检索、第二轮复用），要么明确记录检索次数差异并在分析中控制。**建议统一为"每任务最多一次检索"**，让差异只来自"何时注入"。
3. **轮次/调用预算**：所有臂都是两轮讨论 + 一次汇总，Agent 数量、轮数、汇总 prompt 完全一致。唯一变量是证据注入时机。

另外固定：同一批问题、同一模型版本、同一 temperature、同一检索器与 top-k、同一随机种子集（每问题跑 3–5 次取均值以降方差）。

## 4. 看什么结果

**主指标（决定去留）**
- 任务准确率 / 正确率（按你的任务定义，最好有自动可判定的 ground truth）。
- 相对 A 的提升（H1）和相对 B 的差距（H2）。

**机制指标（解释为什么）**
- **证据采纳率**：第二轮回答中，最终结论是否引用了证据内容（可用 LLM 判官或关键词/引用检测）。这是判断"延迟注入是否真被用上"的核心。
- **第一轮答案 vs 最终答案的翻转率**：C 臂里有多少比例因第二轮证据而改变结论。翻转率高且翻转后更准 = 设计有效；翻转率低 = 证据没起作用。
- **Agent 间分歧度**：第一轮三 Agent 答案的一致性，以及第二轮后是否收敛。延迟证据的一个理论好处是"先独立、后纠偏"，这个指标能验证该机制。
- **成本**：总 token、检索次数、延迟（wall-clock）。

**统计**：每臂每问题多次运行，报告均值 ± 置信区间；用配对检验（同问题跨臂比较），样本量建议至少 50–100 题，否则差异会被噪声淹没。

## 5. 什么结果会让你建议停止

建议**停止（不做这个改动）**的信号：

1. **C 不显著优于 A**：延迟证据没带来可测收益 → 直接停。
2. **C 显著劣于 B**：延迟注入损失了准确率，且差距超过你预设的实用阈值（比如 >3–5 个百分点）→ 停，除非你有明确的成本理由。
3. **C ≈ D**：说明收益来自"第一轮有证据"，第二轮注入是摆设 → 停，改回第一轮注入。
4. **证据采纳率低**（比如 <30%）：第二轮 Agent 基本无视证据 → 设计无效，停或先修 prompt。
5. **翻转率低但准确率也没提升**：证据既没改变结论也没帮忙 → 停。
6. **成本不降反升**：如果延迟注入没省下检索/token，却增加了复杂度和延迟 → 没有工程理由继续。

建议**继续/扩大实验**的信号：C 显著优于 A、与 B 差距在阈值内（非劣）、证据采纳率和"翻转后变准"的比例都高——这时才值得投入更大规模验证或上线 A/B。

## 6. 一个提醒

你这个设计的隐含卖点是"第一轮独立回答避免证据锚定，第二轮再纠偏"。如果这是你的真实动机，**除了准确率，一定要测"锚定效应"**：比较 B 臂第一轮答案与最终答案的相似度 vs C 臂。如果 B 臂第一轮就被证据带偏、C 臂第一轮更独立，这才是延迟注入的独特价值，也是唯一能让 C 在准确率不占优时仍值得保留的理由。否则，单看准确率，B 臂通常不会输。
