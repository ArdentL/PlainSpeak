# 教师：把家长通知写得清楚、自然

[返回场景列表](../README.md) · [完整调用记录](data/07-teacher.json)

## 用户问题

我是小学老师，帮我给家长群写一条通知：原定本周五的春游因天气预报有雨延期，新日期下周一再通知；周五照常到校上课，穿校服，不用带野餐垫和零食；已经交的活动费用先保留，确定新日期后再安排。不要让家长看完还得追问周五到底来不来学校。

## 回答对比

左侧是 DeepSeek 提供的原始版本；右侧是另一次对话的回复。在应用该插件的语言规则后，进行了本地中文→英文→中文回译。这两种版本均代表了实际返回的完整文本。

## 这组有什么变化

只加写作规则的通知已将延期、周五照常上课、穿校服、无需带物品和费用安排放在一段里。回译却写成“穿着校服参加活动”，与周五照常上课的意思冲突；这条通知更适合使用中间稿。
